# bitcoin-pq-opcode

Working journal for a prototype of the post-quantum signature piece
that BIP 360 leaves open and BIP 361 lists as a TBD requirement: a
tapscript opcode that verifies a PQ signature, built and measured on
regtest on top of my BIP 360 P2MR implementation
(https://github.com/jeanpablojp/bitcoin/tree/p2mr-regtest, journal at
https://github.com/jeanpablojp/bitcoin-p2mr).

Notes live in NOTES.md. Same working method as the P2MR project:
implement, measure, publish the numbers.
